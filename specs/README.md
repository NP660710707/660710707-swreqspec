# ดัชนี specs

| โฟลเดอร์ | Use case | ฟีเจอร์ | สถานะ | ผู้รับผิดชอบ |
|---|---|---|---|---|
| 001-booking | UC-01 | จองคิวตรวจสุขภาพ (ตัวอย่างของรายวิชา) มี spec.md v3 plan.md และ mockups 3 หน้า | Draft v3 | ผู้สอน |

กติกา: 1 โฟลเดอร์ = 1 ฟีเจอร์ระดับ use case ชื่อโฟลเดอร์ขึ้นต้นด้วยเลข 3 หลัก ตามด้วยชื่อฟีเจอร์ภาษาอังกฤษตัวเล็ก

ของที่ใช้ร่วมหลายฟีเจอร์ (Constraint, data model, glossary, mockup ส่วนกลาง) อยู่ที่ `000-shared/` เขียนที่เดียว spec ของฟีเจอร์อ้าง ID (ดูวิธีใน `docs/shared-spec-guide.md`)

แบบหน้าจอที่ตกลงกับผู้ใช้แล้ว วางไว้ใน `mockups/` ของโฟลเดอร์ฟีเจอร์นั้น (ดูวิธีใน `docs/mockup-guide.md`) ทุกครั้งที่ spec เปลี่ยนเวอร์ชัน เพิ่ม 1 รายการใน `specs/CHANGELOG.md`
